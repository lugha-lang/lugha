# E0473: `spawn` through something that isn't a scope

`x.spawn(call)` starts a task in the scope `x` names, so `x` must be a
`Scope`: the name `scope s { … }` gives, a parameter of that type, or
the root scope `main` takes.

```lugha
fun work(): i64 = 42;

fun main() {
    let x = 1;
    let t = x.spawn(work()); // error: E0473
}
```

Start the task in a scope:

```lugha
fun work(): i64 = 42;

fun main(console: Console) {
    let r = scope s {
        let t = s.spawn(work());
        t.join().unwrap()
    };
    console.println(r.unwrap());
}
```
