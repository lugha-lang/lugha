# E0334: A program using OpenSSL can't be built for another platform

`std.tls`, `std.http` (which speaks `https://` through `std.tls`) and
`std.crypto` are linked with OpenSSL, and the OpenSSL at hand is this
machine's. It fits builds for this machine only: linking it into a program
for another platform (`--target` naming any other) would give a program
that can't run there, or one built against the wrong library. So such a
build stops at the import.

```text
import std.crypto; // error: E0334 (with --target=x86_64-unknown-linux-musl)

fun main(console: Console) {
    console.println(crypto.sha256([]).len);
}
```

Build without `--target`, for this machine:

```text
lughac build app.la
```

or build on the target platform itself. Programs that don't use these
modules build for any target.

`lughac check` and the editor don't link, so they never report this.
