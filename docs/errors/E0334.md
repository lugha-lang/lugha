# E0334: A program using OpenSSL can't be built for another platform

`std.tls`, `std.http` (which speaks `https://` through `std.tls`) and
`std.crypto` are linked with OpenSSL 3.2 or newer. This machine's OpenSSL
fits builds for this machine only, so a build for another platform
(`--target` naming any other) needs an OpenSSL built for that platform.
Without one, the build stops at the import.

```text
import std.crypto; // error: E0334 (with --target=aarch64-apple-darwin)

fun main(console: Console) {
    console.println(crypto.sha256([]).len);
}
```

Name a folder holding OpenSSL built for the target, in the variable
`LUGHA_OPENSSL_` followed by the target in capitals, `-` written `_`:

```text
export LUGHA_OPENSSL_AARCH64_APPLE_DARWIN=/home/me/openssl-mac
lughac build app.la --target=aarch64-apple-darwin
```

The folder holds `include/openssl/`, `lib/libssl.a` and `lib/libcrypto.a`.
They are linked into the program, so it runs with nothing installed; an
OpenSSL security fix reaches it when it is rebuilt with a fixed folder.
OpenSSL's `Configure` builds one with `zig cc -target …` as its compiler
(`no-shared`).

Or build without `--target`, for this machine. Programs that don't use
these modules build for any target.

`lughac check` and the editor don't link, so they never report this.
