# E0422: A type that doesn't implement an interface, or an `impl` that doesn't match it

A type implements an interface only by saying so, in an `impl I for T { … }`
block. Having methods of the right names and types isn't enough. This error
says a type is used as `T: Shape`, converted to the interface type `Shape`,
or called as `Shape.area(x)`, without such a block.

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Square {
    fun area(self): f64 = self.side * self.side;
}

fun total_area<T: Shape>(shapes: T[]): f64 {
    let mut sum = 0.0;
    for s of shapes {
        sum += s.area();
    }
    sum
}

fun main() {
    println(total_area([Square { side: 1.0 }])); // error: E0422
}
```

Implement the interface:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Shape for Square {
    fun area(self): f64 = self.side * self.side;
}

fun total_area<T: Shape>(shapes: T[]): f64 {
    let mut sum = 0.0;
    for s of shapes {
        sum += s.area();
    }
    sum
}

fun main() {
    println(total_area([Square { side: 1.0 }, Square { side: 2.0 }]));
}
```

The same code marks an `impl` block that doesn't match its interface: an
item without a default left out, an item with another signature, or a
method the interface doesn't declare. The help lists each. A type parameter
meets an interface through its bounds, and an interface value meets another
interface when it declares every item that one needs; when either falls
short, the help names what is missing.
