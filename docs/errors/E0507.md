# E0507: Changing the array a `for … of mut` loop writes

`for x of mut xs` gives a changeable binding for each element and writes
it back to `xs` as the loop goes, so while it runs `xs` itself can't
change: not by assignment to it or its elements, not by `push`, `pop` or
`clear`, not through a `mut self` method or `swap`. Such a change would
be undone, or land on an element the loop is about to write. The same
goes for calling `it.next()` on an iterator inside `for n of mut it`.

```lugha
fun main(console: Console) {
    let mut xs = [1, 2, 3];
    for x of mut xs {
        xs.push(x); // error: E0507
    }
    console.println(xs.debug());
}
```

A plain `for x of xs` holds the array as it was when it started, so its
body may change `xs`; the loop goes on over what it started with:

```lugha
fun main(console: Console) {
    let mut xs = [1, 2, 3];
    for x of xs {
        xs.push(x * 10);
    }
    console.println(xs.debug());
}
```

To change the elements as you go, use `mut` and change only the binding:

```lugha
fun main(console: Console) {
    let mut xs = [1, 2, 3];
    for x of mut xs {
        x *= 10;
    }
    console.println(xs.debug());
}
```
