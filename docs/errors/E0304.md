# E0304: `main` with the wrong signature, generic, or outside the main file

`main` is called by the runtime, which has to supply every parameter. So
it takes only what the runtime can give, matched by type in any order and
with any names, each at most once: `string[]` (the command-line
arguments, the program's path first), `Console` and `Fs`. It returns `()`
or an `i32` exit code, and has no type parameters. A `main` inside an
imported module is reported too: there is only one entry point.

```lugha
fun main(n: i64) { // error: E0304
}
```

Take what the runtime gives, and work out the rest inside `main`:

```lugha
fun main(args: string[], console: Console) {
    let n = args.len;
    console.println(n);
}
```

To choose the exit code, return an `i32`, not another type:

```lugha
fun main(): i64 { // error: E0304
    1
}
```

```lugha
fun main(): i32 {
    1
}
```
