# E0335: `pkg-config` can't be used when building for another platform

A `[link]` table's `pkg-config` line asks this machine's `pkg-config` which
folders and libraries a C library needs. Its answers describe this
machine's libraries, which don't fit a program built for another platform
(`--target` naming any other), so such a build stops at that line before
`pkg-config` runs.

```text
[link]
pkg-config = ["sqlite3"]   # error: E0335 (with --target=aarch64-unknown-linux-musl)
```

Name the target's own libraries instead, with `libs` and the folder
holding them in `paths`:

```text
[link]
libs = ["sqlite3"]
paths = ["vendor/aarch64-musl/lib"]
```

or build without `--target`, for this machine. `c` files are compiled for
the target as usual.
