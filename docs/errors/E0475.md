# E0475: A value that can't cross to another task

A value that crosses to another task must be **sendable**: nothing in it
may be shared and changed by two tasks at once. What crosses: a spawned
call's arguments, what it captures and its result; what a channel
carries; and an actor's fields, its messages' parameters and results.

A type is sendable when its parts are, worked out by the compiler: numbers,
text, arrays, structs, enums and tuples of sendable parts, channels of
them, actors, capabilities, and functions that captured only sendable
values. A `Ref` never is: it is a box two tasks would share. Nor is a plain
`fun(…)` value, which may have captured anything, or an interface value
whose interface doesn't require `Sendable`.

```lugha
fun main() {
    let hits = Ref.new(0);
    let r = scope s {
        s.spawn(fun() { hits.set(1); }()); // error: E0475
    };
}
```

State that tasks share belongs to an actor, which one task owns, and which
the others send messages:

```lugha
actor Hits {
    count: i64,
    fun add(mut self) { self.count += 1; }
    fun get(self): i64 = self.count;
}

fun main(console: Console) {
    let hits = spawn Hits { count: 0 };
    let r = scope s {
        s.spawn(hits.add());
        s.spawn(hits.add());
    };
    console.println(hits.get());
    hits.stop();
}
```

Or tasks send what they found back through a channel:

```lugha
fun count(found: Sender<i64>) {
    found.send(1);
}

fun main(console: Console) {
    let (found, counts) = Chan<i64>.new(2);
    let r = scope s {
        s.spawn(count(found));
        s.spawn(count(found));
    };
    found.close();
    let mut total = 0;
    for n of counts {
        total += n;
    }
    console.println(total);
}
```

Generic code that sends a `T` asks for a sendable one:

```lugha
fun relay<T: Sendable>(s: Scope, value: T, out: Sender<T>) {
    s.spawn(out.send(value));
}

fun main() {}
```

A capability may be handed to other tasks, so a type implementing one
(`Console`, `Dir`, `Conn`, …) must be sendable too: a fake that records
what it was told keeps that in an actor.
