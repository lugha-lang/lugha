# E0337: Retired in v18

This code is never reported and will never be reused for anything else.

Until milestone 271 a build for Windows (`--target=x86_64-pc-windows-gnu`)
stopped at each `extern struct` passed to or from C by value, since
lughac didn't yet lower Windows x64's rules for them. Now it does: a
struct of exactly 1, 2, 4 or 8 bytes travels as one integer, and any
other as a pointer to a copy the caller makes, as clang and MSVC pass it.

```lugha
extern struct Point { x: f64, y: f64 }
extern fun length(p: Point): f64;   // builds for every target

fun main(console: Console) {
    console.println(length(Point { x: 3.0, y: 4.0 }));
}
```
