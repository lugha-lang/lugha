# E0210: An unknown or misplaced attribute

An attribute `@name` sits before an item or a method. Lugha has two:
`@test` goes only before a function, marking it as a test that `lughac
test` runs; `@caller_location` goes before a function or a type's own
method, making its panics report the place it was called from. Any other
name, or either one where it can't apply, is this error; the item itself
is still read.

```lugha
@inline // error: E0210
fun double(x: i64): i64 = x * 2;

fun main(console: Console) {
    console.println(double(21));
}
```

Remove the attribute:

```lugha
fun double(x: i64): i64 = x * 2;

fun main(console: Console) {
    console.println(double(21));
}
```

`@test` belongs on a function, not on the type it tests:

```lugha
@test // error: E0210
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    console.println(Point { x: 1, y: 2 }.x);
}
```

```lugha
struct Point { x: i64, y: i64 }

@test
fun point_holds_x() {
    assert(Point { x: 1, y: 2 }.x == 1);
}

fun main(console: Console) {
    console.println(Point { x: 1, y: 2 }.x);
}
```

`@caller_location` needs a call site that knows where it is: an interface's
item is called through tables and bounds, an actor's message through a
mailbox, and nothing calls `main` or a test. Mark a function or a type's
own method instead:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Sq { s: f64 }

impl Shape for Sq {
    @caller_location // error: E0210
    fun area(self): f64 = self.s * self.s;
}

fun main() {}
```

```lugha
struct Sq { s: f64 }

impl Sq {
    @caller_location
    fun side(self): f64 {
        if self.s < 0.0 {
            panic("a negative side");
        }
        self.s
    }
}

fun main(console: Console) {
    console.println(Sq { s: 2.0 }.side());
}
```
