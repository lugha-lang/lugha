# E0468: A variant name used as a binding

In a pattern, a bare name is always a new binding: it matches anything
and names it. A variant is written with a leading dot. So `None` in a
pattern on an `Option` would not test for `None`; it would match every
value. A binding spelled like a variant of the type it binds is
always that mistake, so it is an error.

```lugha
fun main(console: Console) {
    let o: Option<i64> = Some(3);
    match o {
        None => console.println("nothing"), // error: E0468
        .Some(n) => console.println(n),
    }
}
```

Write the dot:

```lugha
fun main(console: Console) {
    let o: Option<i64> = Some(3);
    match o {
        .None => console.println("nothing"),
        .Some(n) => console.println(n),
    }
}
```

The same goes for payload slots (`.Some(Empty)` on an `Option<Shape>`
is `.Some(.Empty)`), `if let`, `while let`, `let … else` and `mut`
(`mut None`). A binding named like a variant of some other type is fine.
