# E0215: An interface's parents separated by `,`

An interface that extends others requires every one of them, as a bound
does, so its parents are joined the way a bound joins interfaces, with
`+`. They were once separated by `,`.

```lugha
interface Store: Eq, Sendable { // error: E0215
    fun size(self): i64;
}

fun main() {}
```

Join them with `+`:

```lugha
interface Store: Eq + Sendable {
    fun size(self): i64;
}

fun main() {}
```

`with` on a struct or enum keeps `,` (`with Eq, Ord`): it lists separate
derivations, not one requirement.
