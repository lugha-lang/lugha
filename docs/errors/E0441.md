# E0441: Retired in v18

This code is never reported and will never be reused for anything else.

Before v18, a float anywhere in a map's key type or a set's value type was
E0441: `NaN != NaN`, so a float key could never be found again. Map keys
and set values now need the `Key` interface, which floats don't implement
(they implement `Eq`, with IEEE rules, but not `Key`), so the same program
is E0451, "`f64` can't be a key". Use an integer instead: cents for money,
or a float's bits with `x.to_bits()` when bit-for-bit identity is what
matters.
