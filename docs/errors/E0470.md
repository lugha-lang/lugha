# E0470: Braces that can't build their type

Braces after a type name are read by the type. A struct takes
`field: value`. A type that implements `FromEntries` takes `key: value`
entries, as `Map` does, and one that implements `FromItems` takes items,
as `Set` does. Anything else can't build the value.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { 1, 2 }; // error: E0470
    let s = Set { "a": 1 };
}
```

Write the form the type takes:

```lugha
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    let p = Point { x: 1, y: 2 };
    let s = Set { "a" };
    console.println("{p.x} {s.len}");
}
```

A type of your own can take entries or items by implementing the
interface; the literal then calls its `from_entries` or `from_items`.

```lugha
struct Bag { n: i64 }

impl FromItems<string> for Bag {
    fun from_items(items: string[]): Bag = Bag { n: items.len };
}

fun main(console: Console) {
    let b = Bag.from_items(["apple", "pear"]);
    console.println(b.n);
}
```

In the module that declares such a type, its braces are still its fields:
that is how it builds itself. There, call `Bag.from_items([…])`; in any
other module, `Bag { "apple", "pear" }` works.
