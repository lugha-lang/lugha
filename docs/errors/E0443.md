# E0443: `out` or `mut` missing or misplaced in a call

An extern's `out`, `ptr` and `mut` parameters are pointers, and the call
says so with the same word: `out place` (C writes it), `ptr e` (C reads a
copy) or `mut place` (C reads and changes it). A Lugha function's `mut`
parameter changes its caller's place the same way, and its call writes
`mut place` too. This error is a call that leaves the word off for such a
parameter, writes a different one, or writes one for a parameter that has
none.

```lugha
fun bump(mut n: i64) {
    n += 1;
}

fun main() {
    let mut count = 0;
    bump(count); // error: E0443
}
```

Write `mut` at the call, so it is plain that `count` changes:

```lugha
fun bump(mut n: i64) {
    n += 1;
}

fun main() {
    let mut count = 0;
    bump(mut count);
    println(count);
}
```

The same goes for an extern's parameters:

```text
// main.la, with get_fuel in a C file linked through [link]
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(fuel); // error: E0443
}
```

Write `out` before the place:

```text
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(out fuel);
    println(fuel);
}
```

The examples call C, so they aren't checked as programs here.
