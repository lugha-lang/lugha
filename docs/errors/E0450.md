# E0450: A type that can't be turned into JSON

`json.encode` (and anything with a `T: json.Json` bound) takes data only:
numbers, `bool`, `char`, `string`, `()`, arrays, tuples, maps whose keys
are strings or integers, sets, `Option`, `json.Value`, and structs and
enums made of these that ask for it with `with json.Json`. A function,
closure, interface value, `Ref`, task, channel, actor handle or C handle
has no JSON form, and neither does a map keyed by anything else. The
message names the path to the first part that isn't data: at the
declaration that asks, or where a value is encoded.

```lugha
import std.json;

struct Job {
    name: string,
    run: fun(): (),
} with json.Json // error: E0450

fun main() {
    let job = Job { name: "backup", run: fun() {} };
    let v = json.encode(job);
}
```

Encode the data and keep the behaviour out of it:

```lugha
import std.json;

struct JobInfo {
    name: string,
} with json.Json

fun main() {
    let v = json.encode(JobInfo { name: "backup" });
    println(json.stringify(v).unwrap());
}
```

A generic function passes its parameter through by asking for the bound:

```lugha
import std.json;

fun save<T: json.Json>(x: T): string = json.stringify(json.encode(x)).unwrap_or("");

fun main() {
    println(save([1, 2]));
}
```
