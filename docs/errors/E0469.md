# E0469: A cast that can lose information

`as` converts a number only where every value survives: widening an
integer (`u8 as i64`), an integer into a float that holds all its values
(`i32 as f64`), `f32 as f64`, and a `char` to its code point. Anything
else could change the value without a word, so `as` refuses it.

```lugha
fun main(console: Console) {
    let big: i64 = 300;
    let b = big as u8; // error: E0469
    console.println(b);
}
```

Name the conversion you mean. Each method takes its target as a type
argument:

```lugha
fun main(console: Console) {
    let big: i64 = 300;
    console.println(big.truncate<u8>());          // 44: the low bits
    console.println(big.saturate<u8>());          // 255: clamped to the range
    console.println(big.try_into<u8>().debug());  // None: it doesn't fit
    console.println(2.5.round<i64>());            // 3: halves away from zero
    console.println(big.round<f64>());            // 300.0: the nearest f64
}
```

- `truncate` keeps an integer's low bits.
- `saturate` gives the nearest value in range; from a float it rounds
  toward zero and NaN becomes 0, as `as` once did.
- `round`, `floor` and `ceil` round the named way and panic if the result
  doesn't fit; `round` also gives an integer's nearest float.
- `try_into` gives an `Option`, `None` unless the value converts exactly;
  `n.try_into<char>()` checks for a valid code point.

In generic code, `as` works only when it is lossless at every type the
bound admits; `saturate`, `round` and `try_into` work at any of them.
