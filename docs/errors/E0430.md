# E0430: Retired in v18

This code is never reported and will never be reused for anything else.

Before v18, a type satisfied an interface by having its methods, so a
default method could reach a type from any interface it happened to match,
and `c.describe()` was E0430 when two visible interfaces both supplied a
default `describe`. A type now implements an interface only through
`impl I for T`, and two implemented interfaces sharing a method name is
E0460, which suggests calling the item through one of them:
`Named.describe(c)`.
