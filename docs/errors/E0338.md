# E0338: A shared library has no `main`, and something C calls

`lughac build --shared` makes a shared library: C loads it and calls its
functions by name, `extern fun name(…) { … }`. Those functions are its
entry points, so it has no `main`, and it needs at least one of them.

```text
$ lughac build --shared app.la
error[E0338]: a shared library has no `main`
```

Remove `main` (or build a program, without `--shared`), and give C a
function to call:

```lugha
extern fun add(a: i64, b: i64): i64 = a + b;
```
