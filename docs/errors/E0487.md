# E0487: Java can't call a function the library exports

`lughac build --shared --jni com.example.Words` gives Kotlin and Java a
method for every function C calls by name (`extern fun … { … }`). Java
takes `i8`, `i16`, `i32`, `i64`, `f32`, `f64`, `bool`, `char` (an `int`),
`string`, `Option<string>` (a parameter only) and handles (a `long`). It
has no unsigned integers and no struct values, so an export taking or
giving one is this error under `--jni`. So is a method name Java reserves
(with `--jni-lang java`), or two exports that become one method name
(`word_count` and `wordCount`).

```text
$ lughac build --shared --jni com.example.Words words.la
error[E0487]: Java can't call this: `u8`
```

Take a signed integer wide enough instead, or keep a struct on the Lugha
side behind a handle:

```lugha
extern fun brightness(level: i32): i32 = level * 2;
```
