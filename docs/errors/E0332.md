# E0332: A program needs OpenSSL 3.2 or newer, which isn't installed

A program that uses TLS or cryptography — `std.tls`, `std.http` (which
speaks `https://` through `std.tls`) or `std.crypto` — is linked with the
system's OpenSSL, version 3.2 or newer. This machine either has no OpenSSL
development files (`openssl/ssl.h`, `libssl`, `libcrypto`) or has an older
OpenSSL, so the program can't be built. Other programs build as before.

```text
import std.crypto; // error: E0332 (on a machine without libssl-dev)

fun main(console: Console) {
    console.println(crypto.sha256([]).len);
}
```

Install them and build again:

```text
sudo apt install libssl-dev
```

`openssl version` says which OpenSSL is installed. Ubuntu 24.04's is 3.0,
which is too old: a newer Ubuntu (25.04 or later) or an OpenSSL built from
source is needed.

`lughac check` and the editor don't link, so they never report this.
