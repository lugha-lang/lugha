# E0483: A view outlives its call

A view, `View<T>` or `MutView<T>`, is C's memory: a pointer and a count,
given to a callback for the length of C's call, or made by `p.view(n, f)`
for the length of `f`. C decides when that memory goes, so a view may
only be used during the call it was given to: read, indexed, written
(`MutView`), sliced, looped over and passed to other functions. It can't be
kept anywhere that could outlive the call: a field, a function's result,
an `Option`, an array, a tuple, a box, a channel, a closure's captures or
a type argument (`id(v)` for a generic `id`).

```lugha
extern fun on_block(f: direct fun(View<u8>, data), user: data);

fun main() {
    on_block(fun(v: View<u8>) {
        let first = Some(v);  // error: E0483
    });
}
```

Copy what must be kept, with `to_array()`:

```lugha
extern fun on_block(f: direct fun(View<u8>, data), user: data);

fun main() {
    on_block(fun(v: View<u8>) {
        let kept: u8[] = v.to_array();
    });
}
```
