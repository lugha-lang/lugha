# E0213: A `#{…}` literal

Maps and sets were once written `#{"a": 1}` and `#{1, 2}`, the first
entry deciding which. Now the literal names its type, so an empty one
needs no guessing and any collection can use the same braces.

```lugha
fun main() {
    let ages = #{"ann": 31, "bo": 40}; // error: E0213
}
```

Write the type's name before the braces:

```lugha
fun main() {
    let ages = Map { "ann": 31, "bo": 40 };
    let primes = Set { 2, 3, 5 };
    let none: Map<string, i64> = Map {};
    println("{ages.len} {primes.len} {none.len}");
}
```
