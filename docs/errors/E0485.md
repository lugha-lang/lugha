# E0485: A function C calls takes or gives what C can't pass

An `extern fun` with a body is a Lugha function C calls by its name. C
passes it numbers, `bool`, `char`, `string` (C's text, copied), `Option<string>`
(a parameter only; `NULL` is `None`), handles, `Option` of a handle and
extern structs, and takes the same back (a `string` as its own copy, freed
with `free()`). Anything else is this error: arrays, Lugha structs and
enums, function values, `out` and `mut` parameters, callbacks.

A capability is this error too: when C calls the function, there is no
`main` to hand it one, so an exported function gets no capabilities.

```lugha
extern fun total(xs: i64[]): i64 = xs.len; // error: E0485

fun main() {}
```

Pass what C has instead, here a count and C's numbers one at a time, or
keep the data on the Lugha side behind a handle:

```lugha
extern fun total(count: i64): i64 = count;

fun main() {}
```
