# E0454: Retired in v18

This code is never reported and will never be reused for anything else.

Before v18, a struct or enum could write its own `eq` and `hash` methods,
and writing one without the other was E0454, since equal values must hash
equal. Equality and hashing are now the `Eq` and `Key` interfaces, written
by hand in `impl Eq for T { … }` and `impl Key for T { … }`. `Key` extends
`Eq`, so a type implementing `Key` without `Eq` is E0422, and a type's own
methods named `eq` or `hash` no longer count for either.
