# E0411: Not indexable or not iterable

A value was indexed with `[…]` or looped over with `for … of`, but its
type supports neither. Arrays and strings can be indexed; arrays,
strings, views, channels' receiving ends and types that implement
`Iter<T>` can be looped over. Other values, such as a plain number, have
no elements.

```lugha
fun main(console: Console) {
    let n = 42;
    console.println(n[0]); // error: E0411
}
```

Index an array, or use the number directly:

```lugha
fun main(console: Console) {
    let ns = [42];
    console.println(ns[0]);
}
```

To loop a number of times, use a range with `in`, not `of`:

```lugha
fun main(console: Console) {
    for c of 5 { // error: E0411
        console.println(c);
    }
}
```

```lugha
fun main(console: Console) {
    for c in 0..5 {
        console.println(c);
    }
}
```

A type is looped over only through `impl Iter<T> for …`: a method that is
merely named `next` doesn't make it an iterator.

```lugha
struct Count { n: i64 }

impl Count {
    fun next(mut self): Option<i64> = None;
}

fun main() {
    for x of (Count { n: 0 }) { // error: E0411
    }
}
```

Say that it is one, and its `next` is the block's:

```lugha
struct Count { n: i64 }

impl Iter<i64> for Count {
    fun next(mut self): Option<i64> {
        self.n += 1;
        if self.n <= 3 { Some(self.n) } else { None }
    }
}

fun main(console: Console) {
    for x of (Count { n: 0 }) {
        console.println(x);
    }
}
```

Your own struct, enum or interface can be indexed by giving it the
methods `[ ]` calls: `fun index(self, i: I): T` to read `a[i]`, and
`fun set_index(mut self, i: I, v: T)` to write `a[i] = v`. Several
indexes are one tuple: `a[x, y]` is `a[(x, y)]`.

```lugha
struct Grid { w: i64, cells: f64[] }

fun main(console: Console) {
    let g = Grid { w: 2, cells: [0.0; 4] };
    console.println(g[1, 0]); // error: E0411
}
```

```lugha
struct Grid { w: i64, cells: f64[] }

impl Grid {
    fun index(self, at: (i64, i64)): f64 {
        let (r, c) = at;
        self.cells[r * self.w + c]
    }
}

fun main(console: Console) {
    let g = Grid { w: 2, cells: [0.0; 4] };
    console.println(g[1, 0]);
}
```
