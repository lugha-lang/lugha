# E0462: An interface that can't be derived for this type

`with I` after a struct or enum asks to implement `I` from its `derive`
blocks, so `I` must have a block for every struct, or every enum, as the
type is. An interface without one, such as `Display`, which is never
derived, can't be listed.

```lugha
interface Show {
    fun show(self): string;
}

derive Show for struct {
    fun show(self): string = "a struct";
}

enum Light { Red, Green } with Show // error: E0462

fun main() {}
```

Implement it by hand instead:

```lugha
interface Show {
    fun show(self): string;
}

derive Show for struct {
    fun show(self): string = "a struct";
}

enum Light { Red, Green }

impl Show for Light {
    fun show(self): string = match self {
        .Red => "red",
        .Green => "green",
    };
}

fun main() {}
```
