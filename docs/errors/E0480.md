# E0480: A `blocking` extern takes or gives a pinned handle

A handle declared `pinned` (`extern type Window pinned;`) belongs to the
thread that made it: its C library may only be called there. An `extern
blocking fun` runs on a helper thread while its task waits, which is never
that thread, so it can't take a pinned handle, nor give one back.

```lugha
extern type Window pinned;
extern blocking fun window_load(w: Window, path: string): i64; // error: E0480

fun main() {}
```

Drop `blocking`: the call then runs on the task's own thread, where the
handle was made, and the task stays there.

```lugha
extern type Window pinned;
extern fun window_load(w: Window, path: string): i64;

fun main() {}
```

If the slow part doesn't need the handle (reading a file, say), declare
that part as a `blocking` extern of its own, and pass its result to the
call that does.
