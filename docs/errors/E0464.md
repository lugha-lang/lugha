# E0464: Retired in v18

This code is never reported and will never be reused for anything else.

Until milestone 179 an interface that extends another, `interface Greeter:
Named { … }`, could be a bound but not the type of a value, and using it
as one was E0464. Now it is a type like any interface: a `Greeter` value
also has `Named`'s items, and converts to a `Named`.

```lugha
interface Named {
    fun name(self): string;
}

interface Greeter: Named {
    fun greet(self): string = "hello, {self.name()}";
}

struct Ann {}

impl Named for Ann {
    fun name(self): string = "Ann";
}

impl Greeter for Ann {}

fun main(console: Console) {
    let g: Greeter = Ann {};
    console.println(g.greet());
    console.println(g.name());
}
```
