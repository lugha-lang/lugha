# E0464: An interface that extends another, used as a type

An interface may extend others, `interface Greeter: Named { … }`: a type
implementing `Greeter` must implement `Named` too, and a bound
`T: Greeter` gives `Named`'s items as well. Such an interface can be a
bound, but not yet the type of a value.

```lugha
interface Named {
    fun name(self): string;
}

interface Greeter: Named {
    fun greet(self): string;
}

fun hello(g: Greeter): string = g.greet(); // error: E0464

fun main() {}
```

Take the value through a bound instead:

```lugha
interface Named {
    fun name(self): string;
}

interface Greeter: Named {
    fun greet(self): string;
}

fun hello<T: Greeter>(g: T): string = g.greet();

fun main() {}
```
