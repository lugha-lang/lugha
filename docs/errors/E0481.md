# E0481: No longer reported

This code is never reported and will never be reused for anything else.

It was reported for a `spawned` callback taking `Ref<T[]>`: C's buffer
copied in, then copied back when the callback returned, which a `spawned`
callback, running after C's call, could never do. Callbacks no longer
take `Ref<T[]>` at all. A `direct` or `realtime` callback takes
`MutView<T>`, which writes C's memory in place, and a `spawned` one takes
`T[]`, a copy (E0484 otherwise).
