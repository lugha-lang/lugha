# E0481: A `spawned` callback takes `Ref<T[]>`

A `spawned` callback starts a task in the scope that registered it on each
of C's calls, and C's call returns at once. A callback parameter written
`Ref<T[]>` is C's array that the callback may change, copied back to C
when the callback returns. A `spawned` callback returns to C before it has
even run, so its changes could never reach C.

```lugha
extern fun each_block(f: spawned fun(Ref<i64[]>, data), user: data); // error: E0481

fun main() {}
```

Make the callback `direct`: it then runs during C's call, and C sees what
it wrote once it returns.

```lugha
extern fun each_block(f: direct fun(Ref<i64[]>, data), user: data);

fun main() {}
```

If the callback only reads the array, take `i64[]` instead: a copy, which
a `spawned` callback may take.
