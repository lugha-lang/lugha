# E0461: An interface implemented twice for one type

A type implements an interface once, so every call of the interface's
items on it means one thing. A second `impl I for T` block for the same
interface, at the same type arguments, is rejected.

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Shape for Square {
    fun area(self): f64 = self.side * self.side;
}

impl Shape for Square { // error: E0461
    fun area(self): f64 = 0.0;
}

fun main() {}
```

Keep one block. A generic interface may be implemented once for each of
its argument lists, so these two are different interfaces:

```lugha
interface From<T> {
    fun from(x: T): Self;
}

struct Path { text: string }

impl From<string> for Path {
    fun from(x: string): Path = Path { text: x };
}

impl From<i64> for Path {
    fun from(x: i64): Path = Path { text: "#{x}" };
}

fun main() {}
```

Blocks for built-in types count as the same implementation when one type
could match both: `impl<T: Show> Show for T[]` already covers `Point[]`, so
a second block for `Point[]` is this error too. There is no specialization:

```lugha
interface Show {
    fun show(self): string;
}

struct Point { x: i64 }

impl Show for Point {
    fun show(self): string = "a point";
}

impl<T: Show> Show for T[] {
    fun show(self): string = "some values";
}

impl Show for Point[] { // error: E0461
    fun show(self): string = "some points";
}

fun main() {}
```

Keep the general block, or replace it with blocks for each element type
you need:

```lugha
interface Show {
    fun show(self): string;
}

struct Point { x: i64 }

impl Show for Point[] {
    fun show(self): string = "some points";
}

impl Show for i64[] {
    fun show(self): string = "some numbers";
}

fun main() {
    println([Point { x: 1 }].show());
    println([1, 2].show());
}
```
