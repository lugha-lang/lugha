# E0476: Claiming `Sendable`

Whether a type can cross to another task is worked out from its parts, so
it is never written: `impl Sendable for T` and `with Sendable` are this
error, and so is `auto interface` anywhere but the prelude.

```lugha
struct Point { x: i64, y: i64 }

impl Sendable for Point {} // error: E0476

fun main() {}
```

Write nothing: `Point` is sendable because its fields are.

```lugha
struct Point { x: i64, y: i64 }

fun send(s: Scope, p: Point, out: Sender<Point>) {
    s.spawn(out.send(p));
}

fun main() {}
```

A type holding a `Ref` can't be made sendable by claiming it: keep the
shared state in an actor instead (E0475).
