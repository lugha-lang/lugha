# E0471: Touching the world without a capability

A program can't reach outside itself on its own: printing, reading
input, reading and writing files and the command-line arguments all come
through values `main` is given. `print`, `println`, `eprint`, `eprintln`,
`read_line`, `read_stdin_bytes` and `flush` need a `Console`;
`read_file`, `write_file`, `append_file`, `read_bytes`, `write_bytes` and
`append_bytes` need an `Fs`; the arguments are a `string[]` parameter of
`main`; and `exit` is gone, since a program ends by returning from
`main`.

```lugha
fun main() {
    println("hello"); // error: E0471
}
```

Take the capability in `main` and call through it:

```lugha
fun main(console: Console) {
    console.println("hello");
}
```

A function that prints takes the `Console` as a parameter, so its
signature says what it may do, and a test can hand it a fake:

```lugha
fun greet(console: Console, name: string) {
    console.println("hello, {name}");
}

fun main(args: string[], console: Console, fs: Fs): i32 {
    greet(console, "world");
    match fs.cwd().read_file("notes.txt") {
        .Ok(text) => console.print(text),
        .Err(e) => console.eprintln(e),
    }
    if args.len > 1 { 1 } else { 0 }
}
```
