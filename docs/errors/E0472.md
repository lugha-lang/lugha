# E0472: A scope or task handle kept

A `Scope` (what `scope s { … }` names, or the root scope `main` takes)
and a `Task` (what `s.spawn(…)` gives) are handles on work that ends
with its scope. So a handle goes only where an argument goes: a local,
or a parameter. It can't be returned, kept in a field, an array, a map
or any other value, or captured by a closure, which could outlive the
scope or carry the handle to another task.

```lugha
fun work(n: i64): i64 = n * n;

fun main(console: Console) {
    let r = scope s {
        let ts = [s.spawn(work(1)), s.spawn(work(2))]; // error: E0472
    };
}
```

Join each task where it starts, or let the tasks hand their results
back, through a channel, before the scope ends:

```lugha
fun work(n: i64, out: Sender<i64>) {
    out.send(n * n);
}

fun main(console: Console) {
    let (squares, results) = Chan<i64>.new(2);
    let r = scope s {
        s.spawn(work(1, squares));
        s.spawn(work(2, squares));
    };
    squares.close();
    let mut total = 0;
    for n of results {
        total += n;
    }
    console.println(total);
}
```

A function may take a handle as a parameter, to start tasks in its
caller's scope:

```lugha
fun work(n: i64): i64 = n * n;

fun start_two(s: Scope) {
    s.spawn(work(1));
    s.spawn(work(2));
}

fun main(console: Console) {
    let r = scope s {
        start_two(s);
    };
    console.println(r.is_ok());
}
```
