# E0438: A `spawn` that changes a copy, or a malformed `select`

A task gets copies of what its call uses, as a closure does. A
call that changes its receiver — `push`, `pop` or `clear` on an array,
a `mut self` method, `swap` — would change the new task's own copy,
which nobody else ever sees:

```lugha
fun main(console: Console, root: Scope) {
    let mut xs = [1, 2];
    root.spawn(xs.push(3)); // error: E0438
    console.println(xs.debug());
}
```

Send the new value back through a channel:

```lugha
fun grown(xs: i64[], out: Sender<i64[]>) {
    let mut ys = xs;
    ys.push(3);
    out.send(ys);
}

fun main(console: Console, root: Scope) {
    let xs = [1, 2];
    let (back, grown_xs) = Chan<i64[]>.new(1);
    root.spawn(grown(xs, back));
    console.println(grown_xs.recv().unwrap().debug());
}
```

A `select` waits on channels, so it needs at least one `recv` or `send`
arm. It may have one `after(ms)` arm, which runs when nothing happened in
time, or one `default` arm, which runs at once when nothing is ready, but
not both: with `default` the `select` never waits, so the timeout could
never fire.

```lugha
fun main(console: Console) {
    let (tx, c) = Chan<i64>.new(0);
    select {
        m = c.recv() => console.println(m.debug()),
        after(10) => console.println("late"),
        default => console.println("nothing yet"), // error: E0438
    }
}
```

Keep the one you mean:

```lugha
fun main(console: Console) {
    let (tx, c) = Chan<i64>.new(0);
    select {
        m = c.recv() => console.println(m.debug()),
        default => console.println("nothing yet"),
    }
}
```

A `recv` arm must be on a channel's `Receiver` and a `send` arm on its
`Sender`: a type with its own `recv` method doesn't make a `select` arm.
