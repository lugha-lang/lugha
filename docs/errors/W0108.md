# W0108: `==` and `<` can disagree

`Ord` promises that `a == b` exactly when `a.cmp(b)` is `Ordering.Equal`.
A type that derives `Eq` (`with Eq`, or `with Key`, which brings it) and
writes `Ord` by hand can break that promise: the derived `==` compares
every field, while a hand-written `cmp` may compare only some. Then two
values can be neither equal nor ordered, and `sort`, `min` and map keys
behave in ways that are hard to see.

```lugha
struct Run { loss: i64, name: string } with Eq // warning: W0108

impl Ord for Run {
    fun cmp(self, o: Run): Ordering =
        if self.loss < o.loss { Ordering.Less }
        else if self.loss > o.loss { Ordering.Greater }
        else { Ordering.Equal };
}

fun main(console: Console) {
    let a = Run { loss: 1, name: "a" };
    let b = Run { loss: 1, name: "b" };
    console.println("{a == b} {a < b} {b < a}"); // false false false
}
```

Write `Eq` to compare what `cmp` compares, so the two agree:

```lugha
struct Run { loss: i64, name: string }

impl Eq for Run {
    fun eq(self, o: Run): bool = self.loss == o.loss;
}

impl Ord for Run {
    fun cmp(self, o: Run): Ordering =
        if self.loss < o.loss { Ordering.Less }
        else if self.loss > o.loss { Ordering.Greater }
        else { Ordering.Equal };
}

fun main(console: Console) {
    let a = Run { loss: 1, name: "a" };
    let b = Run { loss: 1, name: "b" };
    console.println("{a == b} {a < b} {b < a}"); // true false false
}
```

Or, when every field should take part in both, derive both with `with Ord`.

The warning is given only where `==` compares more than one thing: a
struct of two or more fields, or an enum with a payload. A struct of one
field, or an enum whose variants carry nothing (ordered by a rank, say),
has `==` and a `cmp` that nearly always agree, and isn't warned of.
