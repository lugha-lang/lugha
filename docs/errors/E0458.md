# E0458: Retired in v18

This code is never reported and will never be reused for anything else.

Before v18, `impl f64 { fun mul(self, v: V): V }` and `impl shapes.W { … }`
added arithmetic with a type you don't declare on the left, and E0458
rejected one in the wrong place or holding anything but arithmetic.
Operators are now blocks of the prelude's operator interfaces: a number on
the left is `impl Mul<V> for f64 { … }`, written in `V`'s module (elsewhere
it is E0459), and `impl f64 { … }` itself is E0466.
