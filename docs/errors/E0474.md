# E0474: A task started without a scope

Every task starts in a scope, which waits for it, catches its failure,
and stops it if it must: so nothing a program starts outlives the code
that started it. `spawn` alone starts only an actor; a call that isn't
an actor's runs as a task through a scope's handle.

```lugha
fun work(): i64 = 42;

fun main(console: Console) {
    let t = spawn work(); // error: E0474
}
```

Start it in a scope of its own, which ends once its tasks have:

```lugha
fun work(): i64 = 42;

fun main(console: Console) {
    let r = scope s {
        s.spawn(work()).join().unwrap()
    };
    console.println(r.unwrap());
}
```

Or in the root scope `main` takes, whose tasks finish before the
program does:

```lugha
fun work(): i64 = 42;

fun main(console: Console, root: Scope) {
    let t = root.spawn(work());
    console.println(t.join().unwrap());
}
```
