# E0474: A task or an actor started without a scope

Every task and every actor starts in a scope, which waits for it (and
stops an actor once its tasks are done), catches its failure, and stops
it if it must: so nothing a program starts outlives the code that
started it. Both start through a scope's handle.

```lugha
fun work(): i64 = 42;

fun main(console: Console) {
    let t = spawn work(); // error: E0474
}
```

Start it in a scope of its own, which ends once its tasks have:

```lugha
fun work(): i64 = 42;

fun main(console: Console) {
    let r = scope s {
        s.spawn(work()).join().unwrap()
    };
    console.println(r.unwrap());
}
```

Or in the root scope `main` takes, whose tasks finish before the
program does:

```lugha
fun work(): i64 = 42;

fun main(console: Console, root: Scope) {
    let t = root.spawn(work());
    console.println(t.join().unwrap());
}
```

An actor starts the same way, from its state:

```lugha
actor Counter {
    count: i64,
    fun get(self): i64 = self.count;
}

fun main(console: Console) {
    let c = spawn Counter { count: 0 }; // error: E0474
}
```

```lugha
actor Counter {
    count: i64,
    fun get(self): i64 = self.count;
}

fun main(console: Console, root: Scope) {
    let c = root.spawn(Counter { count: 0 });
    console.println(c.get());
}
```
