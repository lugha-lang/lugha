# W0105: A key written twice in a map or set literal

A `Map { … }` or `Set { … }` literal gives the same key twice. In a map the later value
wins, so the earlier entry does nothing; in a set the value is there once
either way. Usually a key was mistyped.

```lugha
fun main(console: Console) {
    let ages = Map { "ann": 31, "bo": 40, "ann": 32 }; // warning: W0105
    console.println(ages.debug());
}
```

Keep one entry per key:

```lugha
fun main(console: Console) {
    let ages = Map { "ann": 32, "bo": 40 };
    console.println(ages.debug());
}
```
