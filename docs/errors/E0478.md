# E0478: A task's error that its scope can't hold

`scope<E> s { … }` fails with a `Failure<E>`, so every task started in it
that returns a `Result` must fail with an `E`, or with an error that
converts to `E` as `?` converts (when `E` is an interface the error
implements).

```lugha
enum SyncError { Net }

impl Display for SyncError {
    fun show(self): string = "network";
}

impl Error for SyncError {}

fun other(): Result<i64, string> = Err("x");

fun main() {
    let r = scope<SyncError> s {
        s.spawn(other()); // error: E0478
    };
}
```

Return the scope's error type from the task:

```lugha
enum SyncError { Net }

impl Display for SyncError {
    fun show(self): string = "network";
}

impl Error for SyncError {}

fun other(): Result<i64, SyncError> = Err(SyncError.Net);

fun main() {
    let r = scope<SyncError> s {
        s.spawn(other());
    };
}
```
