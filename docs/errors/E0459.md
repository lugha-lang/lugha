# E0459: An `impl I for T` written where it may not be

A type implements an interface through an `impl I for T { … }` block, and
that block has a fixed home: the module that declares the interface, or the
module that declares the type. A block for a type built from a program's
type, `Point[]` or `Option<Point>`, may also live in `Point`'s module; one
for a built-in type alone, `f64` or `T[]`, lives in the interface's. So no
two packages can give one type two implementations of one interface.

The block must also be for a type that can implement one: not a function
type, an interface type, a `Ref`, a task, a channel or an actor, nor every
type at once (`impl<T> I for T`). Every parameter of `impl<…>` appears in
the type, and a struct's or enum's block writes its parameters after its
name instead (`impl Show for Box<T>`). The prelude decides `Eq`, `Key` and
`Ord` for built-in types, so a program can't write them. The prelude's
`Iter`, `Display` and operator interfaces, and indexing's `index` and
`set_index`, are still met by their methods' names.

```lugha
interface Show {
    fun label(self): string;
}

impl Show for fun(i64): i64 { // error: E0459
    fun label(self): string = "a function";
}

fun main() {}
```

Implement it for a type of your own that holds the function, or for the
types the function works on:

```lugha
interface Show {
    fun label(self): string;
}

struct Step {
    run: fun(i64): i64,
}

impl Show for Step {
    fun label(self): string = "a step";
}

impl Show for f64 {
    fun label(self): string = "{self}";
}

fun main(console: Console) {
    console.println(Step { run: fun(x: i64): i64 = x + 1 }.label());
    console.println(2.5.label());
}
```

The same error comes from a block in a third module. Here `main.la`
declares neither `Shape` nor `Square`:

```text
import geo;
import shapes;

impl shapes.Shape for geo.Square { // error: E0459
    fun area(self): f64 = self.side * self.side;
}
```

Move the block into `geo.la`, which declares `Square` and writes
`impl shapes.Shape for Square { … }`, or into `shapes.la`, which declares
`Shape` and writes `impl Shape for geo.Square { … }`.
