# E0465: `debug` in an optimized build

`debug(x)` writes a value's debug form to standard error, with the file
and line it was called from, and gives the value back. It is for finding
out what a program does while you work on it, so an optimized build
(`lughac build -O2`, a release) rejects every call that is left in.
`lughac check`, `run` and `test` accept it.

```text
fun main() {
    let total = debug(2 + 3); // error: E0465 under `lughac build -O2`
    println(total);
}
```

Remove the call before building the release, or print what the program
means to show to its users with `println` and a `Display`:

```lugha
fun main(console: Console) {
    let total = 2 + 3;
    console.println(total);
}
```
