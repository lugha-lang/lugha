# E0479: A `blocking` extern takes a callback

An `extern blocking fun` runs on a helper thread while its task waits, and
Lugha code can't run on a helper thread. A callback is Lugha code C calls,
so a `blocking` extern can't take one, nor the `data` and `release`
parameters that go with one.

```lugha
extern blocking fun each(f: direct fun(i64)); // error: E0479

fun main() {}
```

Drop `blocking` if C calls the callback while the call runs: the call then
runs on the program's own thread, as a plain extern does.

```lugha
extern fun each(f: direct fun(i64));

fun main() {}
```

Or keep the slow part `blocking` and do the callback's work in Lugha once
the call has returned. A callback C stored earlier and calls during a
`blocking` call ends the program with a panic saying a C callback ran on a
helper thread.
