# E0103: Unknown escape sequence

A `\` inside a string starts an escape, and only a few exist: `\n`, `\t`,
`\r`, `\\`, `\"`, `\0`, and `\u{1F600}` for any character by its code
point (one to six hex digits, a Unicode scalar value). Any other letter
after `\` is an error rather than being kept as it is, so a typo never
silently changes the text; so is a malformed `\u`, such as `\u41` without
braces or `\u{D800}`, which names no character.

```lugha
fun main(console: Console) {
    // error: E0103
    console.println("C:\data\files");
}
```

To put a backslash in a string, write it twice:

```lugha
fun main(console: Console) {
    console.println("C:\\data\\files");
}
```
