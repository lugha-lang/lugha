# E0212: A variant in a pattern without its leading dot

In a pattern, a variant is written with a dot before its name: `.Some(x)`,
`.Circle(r)`. The dot is how the pattern says "test for this variant";
a bare name is a new binding. A name followed by `(` can't be a binding,
so without the dot it is this error.

```lugha
enum Shape { Circle(f64), Empty }

fun main(console: Console) {
    let s = Shape.Circle(1.0);
    match s {
        Circle(r) => console.println(r), // error: E0212
        .Empty => console.println("empty"),
    }
}
```

Write the dot. The enum's name stays out: the matched value's type gives it.

```lugha
enum Shape { Circle(f64), Empty }

fun main(console: Console) {
    let s = Shape.Circle(1.0);
    match s {
        .Circle(r) => console.println(r),
        .Empty => console.println("empty"),
    }
}
```

Values are built as before, with the enum's name: `Shape.Circle(1.0)`,
`Some(3)`.
