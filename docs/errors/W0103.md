# W0103: Unused `match` binding (warning)

In a pattern, a bare name is always a new binding that matches anything;
a variant is written with a leading dot. So a variant written without its
dot and misspelled, `Emtpy` for `.Empty`, becomes a catch-all instead of a
test. (Spelled right, `Empty` is E0468.) When a binding is never used in
the arm, Lugha warns, since it is almost always a mistake.

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    .Some(.Full(n)) => n,
    .Some(Emtpy) => 0, // warning: W0103
    .None => 0,
};

fun main(console: Console) {
    console.println(count(Some(Cell.Full(3))));
}
```

Write the variant, with its dot:

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    .Some(.Full(n)) => n,
    .Some(.Empty) => 0,
    .None => 0,
};

fun main(console: Console) {
    console.println(count(Some(Cell.Full(3))));
}
```

If you did mean to match anything there, write `_`, which says so:

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    .Some(.Full(n)) => n,
    .Some(_) => 0,
    .None => 0,
};

fun main(console: Console) {
    console.println(count(Some(Cell.Full(3))));
}
```
