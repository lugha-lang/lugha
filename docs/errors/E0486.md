# E0486: Two functions C calls share a name

Every function C calls by name, `extern fun name(…) { … }`, is a C symbol:
its name, or the one in quotes after `extern`. Two in one program with the
same C name would be one symbol defined twice.

```lugha
extern fun area(w: f64, h: f64): f64 = w * h;
extern "area" fun square_area(s: f64): f64 = s * s; // error: E0486

fun main() {}
```

Give one a C name of its own:

```lugha
extern fun area(w: f64, h: f64): f64 = w * h;
extern "square_area" fun square_area(s: f64): f64 = s * s;

fun main() {}
```
