# E0460: A method name two implemented interfaces share

When a type has no method of its own called `describe`, `x.describe()`
looks among the interfaces the type implements, through `impl I for T`, for
one that declares `describe`. If two of them do, the call could mean either
item, so it is rejected.

```lugha
interface Named {
    fun name(self): string;
    fun describe(self): string = "named {self.name()}";
}

interface Shown {
    fun describe(self): string = "shown";
}

struct Circle { r: f64 }

impl Named for Circle {
    fun name(self): string = "circle";
}

impl Shown for Circle {}

fun main() {
    let c = Circle { r: 1.0 };
    println(c.describe()); // error: E0460
}
```

Say which interface you mean by calling the item through it:

```lugha
interface Named {
    fun name(self): string;
    fun describe(self): string = "named {self.name()}";
}

interface Shown {
    fun describe(self): string = "shown";
}

struct Circle { r: f64 }

impl Named for Circle {
    fun name(self): string = "circle";
}

impl Shown for Circle {}

fun main() {
    let c = Circle { r: 1.0 };
    println(Named.describe(c));
    println(Shown.describe(c));
}
```

A method of the type's own, in `impl Circle { … }`, would also settle it:
`c.describe()` always calls the type's own method first.
