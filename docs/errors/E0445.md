# E0445: Not a constant

A constant (`const NAME: T = value;`) is computed once, before `main`. Its
value may be any expression, calls included, as long as it is *pure*:
nothing it runs, directly or through the functions it calls, may reach
outside the program. That rules out `debug`, anything in std that uses the
operating system (files, the network, the clock, the environment, random
numbers, processes), calling an `extern` C function, and starting tasks,
channels or actors; printing and files need a capability, which a constant
never has. Local variables, loops, recursion, arrays, maps, `Ref`,
closures and `panic` are all fine. The help shows the path to what isn't
pure.

A constant's type must also be plain data: numbers, `bool`, `char`,
strings, `()`, and arrays, structs, tuples and enums of those — not
functions, `Ref`, tasks, channels, actors, handles, maps or sets.

```lugha
fun load(): string {
    debug("loading");
    "app"
}

const CONFIG: string = load(); // error: E0445

fun main(console: Console) {
    console.println(CONFIG);
}
```

Compute the value in `main` and pass it on:

```lugha
fun load(fs: Fs): string = match fs.cwd().read_file("app.toml") {
    .Ok(text) => text,
    .Err(_) => "",
};

fun main(console: Console, fs: Fs) {
    let config = load(fs);
    console.println(config);
}
```
