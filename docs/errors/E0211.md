# E0211: `spawn` without a call, a malformed `select` arm, or a shield without a deadline

A task runs one call, so `s.spawn(…)` takes a call: the function and its
arguments, written out, or an actor's state (or the call making it),
which starts the actor. A name alone, a literal or any other expression
is this error.

```lugha
fun work(): i64 = 42;

fun main(root: Scope) {
    let t = root.spawn(work); // error: E0211
}
```

Write the call. To run several statements, call a closure on the spot,
as Go's `go func() { … }()` does:

```lugha
fun work(): i64 = 42;

fun main(console: Console, root: Scope) {
    let t = root.spawn(work());
    let u = root.spawn(fun() {
        console.println("in a task");
    }());
    console.println(t.join().unwrap());
    u.join().unwrap();
}
```

Each arm of a `select` waits for one of four things: a value from a
channel (`name = c.recv()`), room to send (`c.send(value)`), a timeout
(`after(ms)`), or nothing at all (`default`). Anything else before the
`=>` is this error too:

```lugha
fun main(console: Console) {
    let (tx, c) = Chan<i64>.new(1);
    tx.send(1);
    select {
        c.recv() => console.println("got one"), // error: E0211
    }
}
```

Name what `recv` gives, an `Option` that is `None` once the channel is
closed (or `_` to ignore it):

```lugha
fun main(console: Console) {
    let (tx, c) = Chan<i64>.new(1);
    tx.send(1);
    select {
        m = c.recv() => console.println("got {m.debug()}"),
    }
}
```

A shield holds cancellation off while its block runs, and always for a
limited time: a cleanup that hangs must not keep its task from stopping.
`shield` without `within` is this error too:

```lugha
fun main(console: Console) {
    shield { // error: E0211
        console.println("cleaning up");
    }
}
```

Say how long cancellation may wait, in milliseconds:

```lugha
fun main(console: Console) {
    shield within 1_000 {
        console.println("cleaning up");
    }
}
```
