# E0477: A scope setting that doesn't exist, said twice, or two deadlines

A scope's settings come between its name and its body, each at most once:
`independent` (a task's failure is printed and the others run on),
`independent(f)` (each failure goes to `f`), `limit n` (at most `n` of
its tasks run at once), and a deadline: `within ms` (milliseconds from
now) or `until t` (a moment of the monotonic clock); and `pinned` (its
body and tasks stay on one thread), which takes no value. A scope has one
deadline, so `within` and `until` together are this error too.

```lugha
fun main() {
    let r = scope s quickly { // error: E0477
    };
}
```

Write a setting that exists, once:

```lugha
fun work(n: i64): i64 = n;

fun main() {
    let r = scope s independent limit 4 {
        s.spawn(work(1));
    };
}
```

For a deadline, pick one of the two:

```lugha
fun work(n: i64): i64 = n;

fun main() {
    let r = scope s within 2_000 {
        s.spawn(work(1));
    };
}
```
