# E0466: Methods for a type this module doesn't declare

A type's own methods live in the module that declares it: `impl Point { … }`
beside `struct Point`. A number, a type from the prelude or another module's
type can't gain methods anywhere else, so `impl f64 { … }` and
`impl shapes.W { … }` hold nothing.

```lugha
struct V { x: f64 }

impl f64 { // error: E0466
    fun mul(self, v: V): V = V { x: self * v.x };
}

fun main() {}
```

For an operator with such a type on the left, write a block of the
operator's interface, in the module of the right-hand type:

```lugha
struct V { x: f64 }

impl Mul<V> for f64 {
    fun mul(self, v: V): V = V { x: self * v.x };
}

fun main(console: Console) {
    let v = 2.0 * V { x: 1.5 };
    console.println(v.x);
}
```

For any other method, write a function that takes the value:
`fun scaled(k: f64, v: V): V`.
